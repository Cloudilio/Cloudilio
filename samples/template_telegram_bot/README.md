# Telegram bot

1. In Telegram, talk to @BotFather and create a bot. It gives you a token.
2. Add it as `TELEGRAM_BOT_TOKEN` on this app's Environment tab, then deploy.
3. Message your bot. Change `reply_to` in `main.py` to make it do something useful.

The page at the app's address shows whether the bot is running. Previews don't connect to Telegram:
two copies of one bot would take each other's messages.
